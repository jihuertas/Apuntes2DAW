# Curso de Python desde cero

Material organizado para aprender Python de forma progresiva, desde los fundamentos del lenguaje hasta la programación orientada a objetos y la construcción de una aplicación completa.

La idea del curso es que cada tema introduzca únicamente los conceptos necesarios para avanzar al siguiente y que el alumnado pueda reutilizar lo aprendido en prácticas cada vez más completas.

## Cómo utilizar este repositorio

Los ejemplos están pensados para Python 3 y pueden ejecutarse desde terminal, Visual Studio Code, PyCharm o cualquier otro entorno compatible.

## Objetivos generales

Al finalizar el recorrido, el alumnado debería ser capaz de:

- Comprender y escribir programas sencillos en Python.
- Utilizar variables, constantes, tipos y operadores.
- Controlar el flujo de ejecución mediante condicionales y bucles.
- Trabajar con listas, tuplas, conjuntos y diccionarios.
- Dividir un problema en funciones reutilizables.
- Utilizar argumentos variables, funciones lambda y decoradores sencillos.
- Leer y escribir información en ficheros de texto, JSON y CSV.
- Gestionar errores mediante excepciones.
- Organizar aplicaciones con módulos y paquetes.
- Diseñar clases y objetos aplicando encapsulación, herencia y composición.
- Construir una aplicación de consola estructurada en varios archivos.
