# UT4. Persistencia: bases de datos y ORM

**Módulo:** Desarrollo Web en Entorno Servidor (DWES)  

## Descripción

En esta unidad aprenderemos a gestionar la persistencia de información en aplicaciones web utilizando bases de datos relacionales y el sistema de mapeo objeto-relacional (ORM) de Django.

Trabajaremos con modelos, migraciones, relaciones entre entidades y operaciones CRUD, utilizando el ORM para consultar y modificar información sin necesidad de escribir directamente sentencias SQL.

También aprenderemos a utilizar el panel de administración de Django y a configurar diferentes sistemas gestores de bases de datos.

## Objetivos de aprendizaje

Al finalizar esta unidad seremos capaces de:

- Comprender la persistencia de información en aplicaciones web.
- Configurar bases de datos en proyectos Django.
- Definir modelos con distintos tipos de campos y restricciones.
- Crear y aplicar migraciones.
- Realizar operaciones CRUD utilizando el ORM.
- Consultar información mediante filtros, ordenaciones y agregaciones.
- Establecer relaciones uno a uno, uno a muchos y muchos a muchos.
- Garantizar la integridad de los datos y utilizar transacciones.
- Gestionar información desde el panel de administración.
- Configurar Django para trabajar con diferentes gestores de bases de datos.

## Actividades prácticas

A lo largo de la unidad realizaremos las siguientes actividades:

1. Creación de modelos Django.
2. Generación y aplicación de migraciones.
3. Consultas utilizando el ORM.
4. Operaciones CRUD.
5. Diseño de modelos relacionados.
6. Utilización del panel de administración.
7. Desarrollo de aplicaciones que gestionen modelos relacionados.
8. Configuración de proyectos con diferentes gestores de bases de datos.
